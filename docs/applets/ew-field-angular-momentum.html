Момент імпульсу поля: циліндричний конденсатор у магнітному полі

Вигляд зверху вздовж осі. Внутрішня жилка має заряд +q, зовнішня оболонка радіуса R — заряд −q; зовнішнє однорідне B спрямоване вздовж осі (до глядача, ⊙). Електричне E (радіальне) і магнітне B поля утворюють вектор Пойнтінга Π = (c/4π)·E×B, що циркулює навколо осі, тож поле несе момент імпульсу Lп = −qR²B/2c, хоча нічого не рухається. Натисніть «Вимкнути B»: змінне B породжує вихрове E, яке розкручує циліндр, і момент імпульсу переходить від поля до речовини: ω = −qB/(2mc).

Закон збереження: Lп + Lмех = const (сіра лінія). Момент сили, що розкручує циліндр, виникає від вихрового електричного поля Eφ = −(R/2c)·dB/dt, діючого на заряд −q зовнішньої оболонки; жилкою можна знехтувати. Якщо змінити знак q або B, напрям обертання змінюється на протилежний.
