Струм зміщення: зарядка конденсатора

Плоский конденсатор (пластини площею A = πa², на відстані d) заряджається постійним струмом I. Струм провідності I у проводах «продовжується» між пластинами як струм зміщення ID = ε₀·dΦE/dt = ε₀·A·dE/dt. Оскільки Q(t) = I·t і E = Q/(ε₀A), то dE/dt = I/(ε₀A) = const і ID = I. Закон Ампера–Максвелла ∮B·dℓ = μ₀(Iпров + Iзм) дає неперервне поле: навколо проводу B = μ₀I/(2πr); між пластинами на відстані r від осі B = μ₀ID·r/(2πa²); на краю зазору (r = a) B = μ₀ID/(2πa) = μ₀I/(2πa) — зшивається з полем проводу. Без струму зміщення ∮B·dℓ у зазорі дорівнював би нулю і поле «розривалося» б, а з ним — неперервне. Час уповільнено (мкс-масштаб), щоб зарядку було видно; всі числа — у СІ.
