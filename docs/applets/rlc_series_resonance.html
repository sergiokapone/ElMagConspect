Резонанс напруг: послідовний RLC-контур на змінному струмі
Модель: Z = RΣ + i(ωL − 1/ωC); RΣ = R + r + Rс; L = μефL₀; Rс = ωL·tgδ(f), tgδ = tgδ1кГц·f/1 кГц, але не більше 1 (втрати на вихрові струми ∝ f²). V_R — напруга на всіх активних опорах RΣ (включно з втратами в осерді), V_L = ωL·I, як у прикладі з конспекту. Значення μеф і tgδ орієнтовні: для стрижня μеф набагато менша за μ матеріалу (розмагнічувальний фактор); насичення й гістерезис не враховано. В режимі осцилограм u_R — напруга на самому резисторі R (без r). R, L, C — з Parameters.tex; r = 2,5 Ом там задано лише для L = 9 мГн.
