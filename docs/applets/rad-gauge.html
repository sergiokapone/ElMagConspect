Калібрувальні перетворення: A′ = A + ∇f змінює потенціал, але не поле B = rot A

Однорідне магнітне поле B (спрямоване на нас, у площину рисунка) можна описати різними векторними потенціалами. Оберіть початковий вигляд A і додайте градієнт довільної функції f = a·xy + b·(x² − y²)/2 + c·x + d·(x² + y²)/2. Стрілки A зміняться до невпізнання, а rot A в довільній точці й циркуляція ∮A·dl по контуру (= потік B) — ні. Лише складова d змінює ∇·A (калібрування Кулона ∇·A = 0 — при d = 0).

Перетягніть точку P — там обчислюється rot A (скінченними різницями).
