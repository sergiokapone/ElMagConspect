Магнітне поле струмів: закон Біо–Савара

Опис моделі

Закон Біо–Савара: dB = (μ₀/4π)·I·(dℓ × r̂)/r², μ₀ = 4π·10⁻⁷ Тл·м/А. Поле струму обчислюється чисельно як сума полів малих відрізків dℓ провідника. Довгий прямий провід: B = μ₀I/(2πr), концентричні кола (правило свердлика). Виток на осі: B(z) = μ₀I·R²/(2(R²+z²)3/2). Соленоїд: усередині B ≈ μ₀·n·I. Два проводи: поле — векторна сума B₁ + B₂. Проводи перпендикулярні до площини рисунка: ⊙ — струм до глядача, ⊗ — від глядача.

Геометрія:

Рух миші — зонд: стрілка показує вектор B, поруч — компас і |B|. Напрям силових ліній — за стрілками (правило свердлика). Графік |B| — внизу зліва.
