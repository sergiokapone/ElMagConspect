## 📖 Про проєкт

**«Електрика та магнетизм»** — відкритий навчальний посібник, який охоплює повний курс класичної електродинаміки для студентів технічних, фізичних та природничих спеціальностей.

Проєкт поєднує:

- фундаментальні теоретичні відомості;
- математичний апарат електродинаміки;
- сучасне LaTeX-оформлення;
- велику кількість рисунків, схем та ілюстрацій;
- модульну структуру, зручну для подальшого розвитку.

Посібник розробляється як єдина книга з автоматизованою збіркою PDF та можливістю окремої компіляції розділів.
